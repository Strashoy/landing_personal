# Landing de Portafolio Personal

Proyecto PFO1 para la asignatura **Desarrollo de Sistemas Web (Front End)**. Landing breve para presentar perfil, habilidades, proyectos y una forma de contacto.

## URL publicada
https://landing-web-personal.vercel.app

## Perfil de GitHub
https://github.com/Strashoy

## Tecnologías utilizadas
- **HTML5** semántico (`header`, `nav`, `main`, `section`, `article`, `footer`)
- **CSS3** con Flexbox para maquetación de tarjetas y columnas
- **Google Fonts**: Inter (títulos) y Poppins (cuerpo de texto)
- Unidades relativas (`rem`) y modelo de cajas

## Decisiones de diseño
- **Paleta de colores**: Basada en la guía de marca de Rolesencia (Orange Blood `#E8471F`, DeepSkyBlue `#01BAEF`, DarkBlue `#2E4087`, Dark Orchid `#733E9F`).
- **Tipografía**: Inter para jerarquías visuales (títulos), Poppins para cuerpo de texto.
- **Maquetación**: Se utilizó Flexbox para organizar las tarjetas de habilidades y proyectos en una cuadrícula fluida que se adapta a diferentes tamaños de pantalla.
- **Tarjetas interiores**: Cada categoría de proyecto (Desarrollo Mobile y Juegos de Rol) contiene 3 cards con imagen, título y descripción.
- **Transiciones**: Se agregaron transiciones suaves en botones, tarjetas e iconos de redes sociales.
- **Responsive**: Media queries para adaptar el diseño a tabletas y móviles.

## Secciones de la landing
1. **Presentación**: Nombre, perfil y enlaces rápidos
2. **Sobre mí**: Breve descripción profesional
3. **Mis Redes**: Iconos clickeables a redes sociales
4. **Habilidades**: Tarjetas con tecnologías y conocimientos
5. **Proyectos**: Cards interiores con imágenes de mockups y miniaturas de YouTube
6. **Contacto**: Formulario con validación
